# IRON / Training club

A mobile-friendly, static 12-week training companion for two gym sessions per week. Regular sessions programme 16 upper-body and 4 lower-body working sets. Three four-week blocks change compound combinations, rotate accessories, and finish with a recovery week. Recovery sessions use 10 upper and 2 lower sets.

## Build and run

Node.js 20+ is required to generate the site. No runtime framework or network access is required by the deployed site.

```sh
npm ci
npm run build
npm test
npm run serve
```

Open http://localhost:4173. For browser verification, install Chromium once (`npx playwright install chromium`), start the server, and run `npm run test:browser`.

`program.json` and `workouts.csv` are generated by `scripts/create-program.mjs`. Edit that script to change the prescribed exercises, progression, guidance, or cycle start date. The start date is fixed at 27 October 2026 so rebuilding does not reset the cycle. Then run `npm run build` and commit the generated artifacts. `generate-workout-html.mjs` embeds the programme in `workout-plan.html`; `styles.css`, `app.js`, and `vendor/` provide the offline interface.

The cycle uses Australia/Sydney dates. Session labels do not dictate training weekdays. Leave 2–3 days between sessions when possible. The cycle ends at week 12; it does not automatically restart. Checklists and training logs are saved in this browser only, so they do not sync across devices.

## Deployment

Vercel serves this repository as a static site. Set the framework preset to **Other**, with no build command and no output directory. Committed `workout-plan.html` is served at `/` through `vercel.json`; `index.html` is the fallback entry point. Pushes to the connected branch can trigger the existing Vercel integration.

## Training rationale

Compound lifts stay consistent within each four-week block to make progress measurable. The first two lifts use straight sets; later upper-body pairs can alternate when equipment is free. Accessories rotate in the second week of each block for variety. Most working sets leave 2–3 clean reps in reserve. Recovery weeks lower both volume and load. The app includes technique cues, equipment alternatives, warm-up instructions, and double-progression rules.

The 80/20 target counts direct programmed working sets, not physiological muscle contribution. Optional core work and warm-ups are excluded. Visible definition also depends on nutrition and body-fat levels.

The programme is informed by [ACSM's 2026 resistance training guidance](https://acsm.org/resistance-training-guidelines-update-2026/), which emphasises consistency, training major muscle groups at least twice weekly, and adapting training to individual goals. The exercise selection and upper-body bias reflect this project's preferences rather than a prescribed ACSM routine.
